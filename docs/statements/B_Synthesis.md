# B. Novel View Synthesis

## Задача

Дан датасет с данными проездов беспилотных автомобилей. Автомобиль оснащен 6 камерами и лидаром.

Камеры:

- фронтальная;
- задняя;
- две боковые передние;
- две боковые задние.

Для каждого сэмпла предоставлены:

| Данные | Описание |
|---|---|
| 12 изображений | 6 камер x 2 момента времени: `t0` и `t1`, разделенные интервалом 1 или 2 секунды |
| Плотное облако точек | Агрегация всех лидарных сканов рядом с `t0` и `t1`, примерно 10-20 сканов, координаты в мировой системе |
| Позы камер | Матрицы 4x4 `camera-to-world` для всех 12 входных видов и целевого вида |
| Параметры камер | `fx`, `fy`, `cx`, `cy`, `width`, `height`, коэффициенты дисторсии |

Цель: по 12 входным изображениям, облаку точек и позам предсказать изображение с указанной камеры в промежуточный момент времени, примерно в середине между `t0` и `t1`.

Метрика: `PSNR` между предсказанным и ground truth изображением.

Датасет, baseline и вспомогательные файлы доступны по ссылкам, указанным организаторами.

## Оценивание

Тестовый набор разделен на две части:

| Тестсет | Описание |
|---|---|
| Public (`samples`) | Результаты видны на лидерборде во время соревнования. Итоговый скор на лидерборде вычисляется по этой части |
| Private (`tests`) | Результаты скрыты до окончания соревнования. Используется для финального ранжирования |

### Формула PSNR

PSNR для каждого сэмпла вычисляется стандартно:

```text
PSNR = 20 * log10(255 / sqrt(MSE))
```

Где `MSE` - среднеквадратичная ошибка по всем значениям пикселей `R`, `G`, `B` предсказанного и GT изображений.

### Нормализация PSNR

PSNR нормализуется в диапазон `[0, 100]`:

```text
score = (clamp(PSNR, 10, 30) - 10) / 20 * 100
```

Правила:

- `PSNR <= 10 dB` -> `score = 0`;
- `PSNR >= 30 dB` -> `score = 100`;
- итоговый скор - среднее арифметическое нормализованных скоров по всем сэмплам соответствующего тестсета.

## `lidar.npz`

`lidar.npz` содержит плотное облако точек, собранное из лидарных сканов в расширенном окне вокруг `[t0, t1]`.

Временной диапазон агрегации - `3 x delta`:

- один `delta` до `t0`;
- сам интервал `[t0, t1]`;
- один `delta` после `t1`.

Диапазон может обрезаться раньше по границам сцены.

Поля:

| Поле | Описание |
|---|---|
| `xyz` | Координаты точек `(N, 3)`, `float32`, в мировой системе координат |
| `intensity` | Интенсивность отражения `(N,)`, `float32` |

Типичный размер: 300k-1.5M точек, в зависимости от длительности интервала и окружения.

## `meta.json`

Пример структуры:

```json
{
  "sample_id": "2025-02-10_...__000",
  "scene": "2025-02-10_...",
  "delta_s": 1.0,
  "target_camera": "left_bwd",
  "lidar_info": {
    "n_points": 234567,
    "n_sweeps": 12,
    "t0_ns": 1739195519498333000,
    "t1_ns": 1739195520498331000
  },
  "intrinsics": {
    "front": {
      "fx": 1028.5,
      "fy": 1028.5,
      "cx": 960.0,
      "cy": 600.0,
      "width": 1920,
      "height": 1200,
      "distortion_model": "...",
      "distortion_coeffs": []
    },
    "left_fwd": {},
    "left_bwd": {},
    "right_fwd": {},
    "right_bwd": {},
    "rear": {}
  },
  "poses_c2w": {
    "t0": {
      "front": [[0, 0, 0, 0]],
      "left_fwd": []
    },
    "t1": {
      "front": []
    },
    "target": {
      "<target_camera>": []
    }
  }
}
```

Ключевые поля:

| Поле | Описание |
|---|---|
| `target_camera` | Имя камеры, для которой нужно предсказать изображение |
| `delta_s` | Временной интервал между `t0` и `t1`: 1.0 или 2.0 секунды |
| `poses_c2w` | Матрицы `camera-to-world` 4x4 для каждой камеры в каждый момент |
| `intrinsics` | Параметры камер, одинаковые для `t0`, `t1` и `target` одной камеры |

## Система координат

### Камеры (`poses_c2w`)

Матрицы 4x4 `camera-to-world`.

Камерные оси соответствуют OpenCV:

- `x` -> вправо;
- `y` -> вниз;
- `z` -> вперед, в сцену.

### Мировая система (`world frame`)

Основана на позиции автомобиля в начальный момент сцены:

- `x` -> вперед по ходу движения;
- `y` -> влево;
- `z` -> вверх.

### Лидар

Координаты `xyz` в `lidar.npz` находятся в той же мировой системе, что и позы камер.

Облако агрегировано из расширенного окна `[t0 - delta, t1 + delta]`, то есть `3 x delta`, и может обрезаться раньше по границам проезда. Это дает более плотное покрытие сцены.

## Камеры

| Имя | Расположение |
|---|---|
| `front` | Фронтальная, центр лобового стекла |
| `left_fwd` | Левая передняя боковая |
| `left_bwd` | Левая задняя боковая |
| `right_fwd` | Правая передняя боковая |
| `right_bwd` | Правая задняя боковая |
| `rear` | Задняя |
