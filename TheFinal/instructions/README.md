# Instructions

Готовые промпты для работы с `src code` и локальной LM Studio.

Запускать из корня папки `TheFinal`, поэтому пути внутри промптов без префикса `TheFinal/`.

## Порядок использования

1. `00_create_workspace.md`
2. `01_research_start.md`
3. `02_builder_start.md`
4. Дальше цикл: `03_research_next.md` -> `04_builder_next.md`
5. В конце: `05_finalize.md`
6. Для локального брейншторма в LM Studio: `06_lm_studio_research.md`
